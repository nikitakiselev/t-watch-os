# Notes — дизайн

Приложение «Notes» для watchos (LilyGo T-Watch-2020 V3): список голосовых
заметок, просмотр текста с прокруткой, создание/правка через голосовой ввод
(STT), кириллица в тексте.

## Цель и контекст

Пользователь хочет вести короткие текстовые заметки. Ввод с клавиатуры
исключён (T9 на этом железе медленный и без курсора). Вместо этого — **голосовой
ввод** по образцу AI Assistant: показывается микрофон, пользователь проговаривает
текст, сервер распознаёт и возвращает текст, заметка сохраняется. Текст заметок —
**на русском (кириллица, UTF-8)**, поэтому в просмотрщике нужен кириллический шрифт
(в остальной ОС интерфейс намеренно латиница).

Это отличается от первоначальной идеи (клавиатура + редактирование): клавиатура
не используется, правка заметки = повторная запись с **полной перезаписью**.

## Архитектура

Три равноправные `Program` в одном файле `watchos/src/programs/prog_notes.cpp`
(общее статическое состояние модуля). Переключение — штатным стеком ядра
(`kernelOpen`/`kernelBack`). Навбар привязан к `Program`, поэтому у каждого экрана
свой набор кнопок.

| Program            | Экран                       | Навбар              |
|--------------------|-----------------------------|---------------------|
| `notesProgram`     | список заметок              | `[Exit] [New Note]` |
| `notesViewProgram` | просмотр одной заметки       | `[Back] [Edit]`     |
| `notesRecProgram`  | запись голоса → текст        | `[Cancel]`          |

Регистрируется в `appList` только `notesProgram` (точка входа). `view`/`rec`
открываются изнутри через `kernelOpen`.

Поток:
```
список ──тап по выделенной──▶ контекстное меню (модалка)
                                   ├─ Open   ──▶ kernelOpen(view)
                                   └─ Delete ──▶ confirm ──▶ удалить+save
список ──[New Note]──▶ kernelOpen(rec, target=-1)
view   ──[Edit]─────▶ kernelOpen(rec, target=openIdx)
rec    ──распознал──▶ save(target) ──▶ kernelBack()
```

## Хранилище

- SPIFFS, файл `/notes.txt`. **Одна заметка = одна строка** UTF-8 (как
  `stations.txt`). Переводы строк внутри текста при сохранении заменяются пробелом
  (одна заметка не должна занимать больше одной строки).
- В RAM: `static char notes[NOTES_MAX][NOTE_CAP]`, `static int count`.
  - `NOTES_MAX = 16`
  - `NOTE_CAP = 512` байт. Кириллица в UTF-8 ≈ 2 байта/символ → ≈ 250 букв, чего
    хватает под 15-секундную реплику. (Подняли с 256: это уже не латиница.)
- `notesLoad()` — при первом входе/`stationsBegin`-стиле: построчно читаем, пустые
  и пересортные строки пропускаем, обрезаем по `NOTE_CAP-1`.
- `notesSave()` — переписывает весь файл целиком (как удаление станций).
- `notesAdd(text)` — добавить (если `count<NOTES_MAX`), вернуть индекс или -1.
- `notesSet(idx, text)` — перезаписать существующую.
- `notesRemove(idx)` — сдвинуть массив, уменьшить `count`.

## Экран списка (`notesProgram`) — по образцу `prog_wifi`

- Раскладка как в Wi-Fi: заголовок `[ NOTES ]`, ниже список строк.
  `ROW_H ≈ 30` (под кириллический шрифт ~18px + воздух), `VISIBLE ≈ 4`.
- Навигация: `ListNav` + `listNavEvent` — свайп ↑↓ двигает выделение и крутит окно.
- **Тап активирует ВЫДЕЛЕННУЮ заметку** (системное правило — НЕ хит-тест по
  координате) → открывает контекстное меню.
- Заголовок строки = текст заметки, обрезанный по ширине экрана с «…»,
  **рисуется кириллическим VLW-шрифтом** (loadFont вокруг отрисовки строк, чтобы
  статусбар/заголовок/навбар рисовались штатными шрифтами).
- Пустой список → «no notes» по центру.
- `[New Note]` → `kernelOpen(rec)` с `recTargetIdx = -1`. При `count==NOTES_MAX` —
  короткий оверлей «full», запись не открываем.

## Контекстное меню и подтверждение (модалки `modal*`)

По образцу `connectedDialog` в `prog_wifi.cpp`.

- Меню `[Open] [Delete]`: `modalBegin`/`modalPoll`/`modalPanel`. Свайп ↑↓ выбирает
  пункт, тап по выделенному / клик активирует, **тап мимо панели — закрыть**.
  Метки английские (единообразие с остальной ОС; кириллица — только контент).
- «Open» → `kernelOpen(view)` с `openIdx = selected`.
- «Delete» → диалог подтверждения `[Delete] [Cancel]` (тот же каркас) → при
  подтверждении `notesRemove(selected)`, `notesSave()`, перерисовать список.

## Экран просмотрщика (`notesViewProgram`)

- `onEnter`: статусбар + заголовок `[ NOTE ]` штатными шрифтами, затем
  `textViewSetText(notes[openIdx])` + `textViewDraw`.
- Свайпы ↑↓ → `textViewEvent` (листание текста).
- Навбар `[Back] [Edit]`:
  - `[Back]` = `kernelBack` → возврат в список.
  - `[Edit]` → `kernelOpen(rec)` с `recTargetIdx = openIdx`. После распознавания
    заметка перезаписана и сохранена; возврат в просмотрщик (`onEnter` перечитает
    `notes[openIdx]` → покажет новый текст).
- Кнопки `Save` нет: при голосовом вводе сохранение происходит сразу после
  распознавания, отдельный шаг избыточен.

## Запись голоса (`notesRecProgram`) — переиспользует AI Assistant

Структурно копия `prog_assistant.cpp`, но вместо аудио-ответа — получение текста.

- Экран: круглая кнопка-микрофон по центру. **Зажал — пишет, отпустил —
  отправка** (как ассистент: старт по касанию внутри круга, стоп по отпусканию).
  Счётчик секунд над кнопкой, максимум `REC_MAX_SECONDS = 15`.
- Запись: `micCaptureBegin/Read/End` (`sound.h`), буфер `int16 SR*15` в PSRAM
  (`ps_malloc`, как у ассистента), `SR = 16000`.
- Wi-Fi: `wifiAcquire` на входе, `wifiRelease` в `onExit`; перед отправкой при
  необходимости `wifiAutoConnect` (модем после сна гаснет — та же логика, что в
  ассистенте).
- Отправка: `aiTranscribe(sessionId, recBuf, recSamples)` →
  `POST <server>/stt?session=<uuid>`, тело — сырой LPCM. Ответ `{"text":"..."}`.
  - `200` + непустой text → сохранить: если `recTargetIdx < 0` → `notesAdd(text)`,
    иначе `notesSet(recTargetIdx, text)`; `notesSave()`; `kernelBack()`.
  - `204` (не распознано) → бип, вернуться в idle (повтор).
  - иначе (ошибка/нет сети) → бип, idle.
- `keepAwake()` = true, пока не idle (пишет/шлёт) — как ассистент.
- `[Cancel]` = `kernelBack` (прервать без сохранения). `onExit`: `micCaptureEnd`
  (если писал), освободить PSRAM-буфер, `wifiRelease`.
- Сессия: `genSession()` (UUID) как в ассистенте, для совместимости контракта.

### Контракт сервера `/stt`

Новый эндпоинт (реализуется на стороне сервера пользователем):

```
POST /stt?session=<uuid>
Content-Type: application/octet-stream
X-API-Key: <ключ>           (как у /talk, из aiApiKey)
тело: сырой LPCM 16 кГц / 16 бит / моно

200 → {"text":"<распознанный текст в UTF-8>"}
204 → речь не распознана
4xx/5xx → ошибка
```

Текст в JSON — **сырой UTF-8** (только `"` и `\` экранированы, без `\uXXXX`),
чтобы клиент мог извлечь его простым поиском подстроки между кавычками.
`aiTranscribe` делает минимальный un-escape `\"`, `\\`, `\n`.

## Новый компонент `textview.h/.cpp` (корень фреймворка, кириллический)

Переиспользуемый прокручиваемый просмотрщик UTF-8 текста со скроллбаром.
Самодостаточен: сам грузит встроенный VLW-шрифт на время своих операций.

```c
struct TextView {
    int16_t x, y, w, h;          // прямоугольник контента
    const char *text;            // источник (не владеет)
    int  top;                    // первая видимая строка
    int  lineCount, visLines;
    int16_t lineOff[MAX_WRAP_LINES];   // смещения начал строк в text
    int16_t lineLen[MAX_WRAP_LINES];   // длины строк (байт)
};

void textViewInit(TextView&, int x, int y, int w, int h);  // задать рект
void textViewSetText(TextView&, const char *text);          // word-wrap, top=0
void textViewDraw(TextView&);                               // строки + скроллбар
bool textViewEvent(TextView&, InputEvent e);                // свайп ↑↓; true=redraw
```

- **Перенос:** жадный word-wrap по `tft->textWidth(...)` с загруженным VLW-шрифтом.
  Ширина текста = `w - SCROLLBAR_W` (резерв под полосу справа). Слова длиннее
  строки рвутся по символам (с учётом границ UTF-8: не рвать многобайтовый символ).
  Не более `MAX_WRAP_LINES ≈ 64` строк; лишнее усекается.
- **Шрифт:** `loadFont(notesfont)` в начале `textViewSetText`/`textViewDraw`,
  `unloadFont()` в конце — чтобы глобальное состояние `tft` не ломало штатные
  шрифты статусбара/навбара/заголовков.
- **Скроллбар:** справа, шириной `SCROLLBAR_W ≈ 6`. Трек на всю высоту `h`,
  бегунок высотой `h * visLines / lineCount`, позиция `∝ top`. Не рисуется, если
  весь текст помещается (`lineCount <= visLines`).
- **Свайп:** `EVT_DOWN` листает вперёд, `EVT_UP` назад, шаг — постранично
  (`visLines - 1`), с клампом `top` в `[0, max(0, lineCount - visLines)]`.

## Шрифт с кириллицей (`make font`)

- `tools/gen_font.py` генерирует VLW (латиница + кириллица, ~18px) из TTF →
  `watchos/notesfont.h` (C-массив `const uint8_t notesfont[] PROGMEM`). По аналогии
  с `tools/gen_sprites.py` → `sprites_gen.h`.
- Makefile-таргет `make font`. Сам шрифт читается `loadFont(const uint8_t[])` прямо
  из flash (в RAM целиком не копируется).
- Диапазон глифов: ASCII 0x20–0x7E + кириллица U+0410–U+044F + Ёё (U+0401/U+0451).

## Доработки существующего кода

- `aiclient.h/.cpp`: + `struct AiText { int code; String text; };` и
  `AiText aiTranscribe(const char *uuid, const int16_t *pcm, int samples);` —
  переиспользует `aiServerUrl`/`aiApiKey`/scheme-aware соединение из `aiSend`,
  парсит `"text"` вместо `"url"`.
- `apps.cpp`: `#include "src/programs/prog_notes.h"` + `&notesProgram` в `appList`.
- `Makefile`: цель `font` (генерация `notesfont.h`).
- `keyboard.*` — НЕ трогаем (для заметок не используется).

## Иконка приложения

`drawIcon` для списка приложений — простой ASCII/векторный значок «листок/заметка»
(строки текста), рисуется как у других программ.

## Энергосбережение

- `notesProgram` / `notesViewProgram` — обычный сон на простое (`keepAwake`
  отсутствует).
- `notesRecProgram` — `keepAwake()==true` пока идёт запись/отправка (как ассистент).

## Тестирование (ручное, на железе — Serial во сне молчит, диагностика экранная)

- Список: пустой → «no notes»; свайп двигает выделение; тап открывает меню
  выделенной (не той, что под пальцем); прокрутка при >VISIBLE.
- Запись: зажать мик → счётчик; отпустить → «…» → текст сохранён, виден в списке
  кириллицей. `204`/нет сети → бип, без сохранения.
- Просмотр: длинная заметка листается свайпом, скроллбар отражает позицию;
  кириллица читаема.
- Edit: повторная запись полностью заменяет текст; после возврата виден новый.
- Delete: подтверждение; отказ не удаляет; удаление переписывает `/notes.txt`.
- Перезагрузка: заметки сохраняются (читаются из SPIFFS).

## Ограничения (осознанные)

- Правка — только полная перезапись голосом (нет редактирования середины текста).
- 16 заметок, ~250 символов на заметку.
- Метки UI английские; кириллица — только в тексте заметок.
- `/stt` должен быть реализован на сервере; без него голосовые заметки не работают.
